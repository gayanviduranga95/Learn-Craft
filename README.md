## 🌌 About LearnCraft

**LearnCraft** is a student-focused learning platform designed to make education more engaging, interactive, and accessible.

Our vision is to combine a modern learning experience with intelligent educational tools that help students explore concepts, practise skills, and track their progress.

> **Make learning an adventure, not a chore.**

🚧 LearnCraft is currently under development. The current focus is the login interface and responsive frontend.

## ✨ Features

- 🎨 Modern interface with vibrant gradients and glass-inspired styling
- 📱 Responsive layout for desktop, tablet, and mobile
- 🧑‍🎓 Designed with students aged 10–15 in mind
- 🤖 AI-assisted learning features planned

## 🚀 Run Locally

### Prerequisites

Install [Node.js](https://nodejs.org/) and Git.

### 1. Clone the repository

```bash
git clone https://github.com/gayanviduranga95/Learn-Craft.git
```

### 2. Open the application directory

```bash
cd Learn-Craft/learncraft
```

If `package.json` is directly inside the cloned repository, simply run `cd Learn-Craft` instead.

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL printed in your terminal, usually `http://localhost:5173`.
