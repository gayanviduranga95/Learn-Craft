## 🌌 About LearnCraft

**LearnCraft** is a modern learning platform concept focused on helping students explore knowledge, develop skills, and enjoy their educational journey.

Designed with a futuristic visual identity, vibrant colors, and a student-friendly interface, LearnCraft aims to bring technology and education together in one engaging environment.

Our vision is simple:

> **Make learning an adventure, not a chore.**

LearnCraft is currently under active development. The project starts with its responsive login experience, with more learning features planned as development progresses.

## ✨ Highlights

- 🎨 **Modern UI** — A futuristic interface with vibrant gradients and glass-inspired elements.
- 📱 **Responsive Design** — A layout designed to adapt to desktop, tablet, and mobile screens.
- 🧑‍🎓 **Student-Focused Experience** — A visual direction tailored to learners aged 10–15.
- 🤖 **AI-Assisted Learning Vision** — A foundation for future intelligent learning assistance.
- 🧩 **Component-Based Architecture** — React components designed to support future expansion.
- ⚡ **Fast Development** — Vite provides a fast local development workflow.
- 🛠️ **Built to Evolve** — A foundation for future authentication, learning dashboards, and educational tools.

## 🚀 Getting Started

Follow these steps to run LearnCraft locally.

### Prerequisites

Install the following:

- [Node.js](https://nodejs.org/) — preferably a current LTS version
- npm, included with Node.js
- [Git](https://git-scm.com/)

### 1. Clone the repository

```bash
git clone https://github.com/gayanviduranga95/Learn-Craft.git
```

### 2. Enter the project directory

```bash
cd Learn-Craft/learncraft
```

> If your `package.json` is located directly in the cloned repository root, skip the extra `learncraft` directory.

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open LearnCraft

Open the local URL printed in your terminal, usually:

```text
http://localhost:5173
```

You're ready to explore LearnCraft locally! 🎉

## 🔐 Security

- Never commit API keys, passwords, tokens, or private environment files.
- Keep secrets in environment variables and exclude `.env` files from Git.
- Authentication and student-data features should be implemented with security and privacy in mind.
